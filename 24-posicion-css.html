Using position: static;

An element with position: static; is always positioned according to the normal flow of the page:

This div element has position: static;

Using position: relative;

An element with position: relative; is positioned relative to its normal position:

This div element has position: relative;
div.absolute { position: absolute; top: 80px; right: 0; width: 200px; height: 100px; border: 3px solid red; } .topright { position: absolute; top: 8px; right: 16px; font-size: 20px; } .bottomleft { position: absolute; bottom: 8px; left: 16px; font-size: 20px; } .bottomright { position: absolute; bottom: 8px; right: 16px; font-size: 20px; } .center { position: absolute; top: 50%; width: 100%; text-align: center; font-size: 20px; } div.sticky { position: sticky; top: 0; background-color: green; border: 2px solid #4CAF50; }
